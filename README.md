# AshuLab Homebrew tap

```sh
brew install ashulab/tap/carrier
```

Recipes live in `Formula/` (command-line tools) and `Casks/` (macOS apps). A release workflow in [AshuLab/carrier](https://github.com/AshuLab/carrier) rewrites the `carrier` recipes (version, URL, sha256); do not edit them by hand.

The first release has not been cut yet, so `Formula/carrier.rb` is a seed with a placeholder checksum and will not install until it is.
